# Зябра

Локальный переключатель раскладки для Windows и Linux. Если слово набрано не в той раскладке, Зябра стирает его и пишет заново в правильной, затем переключает раскладку.

`ghbdtn` становится `привет`, `руддщ` становится `hello`.

Скачать: [последний релиз](https://github.com/DmNep/zyabra/releases/latest) ([Windows](https://github.com/DmNep/zyabra/releases/latest/download/zyabra-0.1.9.exe), [Linux x86_64](https://github.com/DmNep/zyabra/releases/latest/download/zyabra-0.1.9-linux-x86_64)).

## Что программа не делает

- Не пишет набранный текст на диск и не ведёт журнал клавиш.
- Не использует буфер обмена.
- Не открывает сеть и не скачивает словарь. Сокеты в Linux-версии только местные: сервер X, Sway или Hyprland.
- Не добавляет себя в автозагрузку.
- Не читает обычные поля пароля Windows (флаг `ES_PASSWORD`). На Linux такого признака у клавиш нет, поэтому пароль читается так же, как обычный текст, и тоже остаётся только в памяти.

В памяти держится только текущее незавершённое слово и одна последняя замена: `Pause` перекладывает её снова при каждом нажатии. Кнопка "Пауза" стирает и это. После паузы клавиши не обрабатываются.

На Windows после запуска окно не остаётся на панели задач: Зябра сидит в трее. Щелчок по значку открывает окно, его можно растянуть. Сворачивание и крестик прячут окно обратно в трей. "Выход" завершает программу. Это обычный видимый процесс, не фоновая служба.

## Как это устроено

Идея та же, что у [KeyFlow](https://github.com/weird-mirror/keyflow): буфер одного слова и решение по словарю. Без нейросети. Mahou здесь не образец поведения: там перевод в основном по горячей клавише и есть сетевые проверки обновлений. Зябра исправляет слово сама и наружу не ходит.

```
клавиша → хук → буфер текущего слова
                    ↓
              словари en / ru
                    ↓
      backspace + правильное слово + смена раскладки
```

Слово остаётся как есть, если оно есть в словаре текущей раскладки. Оно меняется, только если в своей раскладке его нет, а те же физические клавиши в другой раскладке дают словарное слово. Если не уверенно ни то ни другое, программа не трогает текст.

Буква сопоставляется по клавише, а не по алфавиту: QWERTY ↔ ЙЦУКЕН. Запятая внутри `cj,frf` — это `б`, поэтому получается `собака`. Запятая после слова остаётся запятой: `ghbdtn,` → `привет,`.

Решение живёт в библиотеке без ввода-вывода (`src/decide.rs`, `src/engine.rs`). Код системы только читает клавиши и печатает замену. На Windows это хук, на Linux — захват `/dev/input` и виртуальная клавиатура. Словари вшиты в программу.

## Управление

- Пробел, Enter, Tab или знак препинания заканчивают слово и могут его исправить.
- `Pause` перекладывает текущее слово даже если его нет в словаре. Каждое следующее нажатие, пока ничего нового не набрано, перекладывает его обратно и снова.
- Вторую такую клавишу можно задать при запуске, ничего не записывая: `zyabra --key 0x2C`. Код десятичный или с префиксом `0x`. На Windows это виртуальный код (`0x2C` — Print Screen), на Linux — код evdev (Print Screen — `99`). Аргумент хранится в ярлыке или в команде, не в Зябре. Если клавиша задана, окно пишет её имя рядом с Pause. Пока Зябра уже запущена, повторный запуск новый код не подхватывает.
- `zyabra help` печатает справку в консоль. В окне тот же текст открывает кнопка "Справка" и пункт меню трея. В ярлыке Windows поле "Объект" такое: `"C:\путь\zyabra.exe" --key 0x2C`. Справка подставляет путь к запущенному файлу. Кавычки вокруг пути нужны, если в нём есть пробел.
- "Пауза" в окне или в меню трея останавливает обработку.
- На Windows сворачивание и крестик прячут окно в трей. "Выход" завершает программу.
- На Linux крестик и "Выход" завершают программу и отпускают клавиатуру.

Нужны установленные раскладки: английская и русская ЙЦУКЕН.

## Linux

Один файл `x86_64-unknown-linux-gnu` подходит обычным дистрибутивам с glibc. Отдельные сборки нужны только для другого процессора или для musl, не для каждого дистрибутива.

Зябра забирает клавиатуру через evdev и отдаёт нажатия обратно виртуальным устройством. Так работает и X11, и Wayland. Раскладку она читает у XKB (переменная `DISPLAY`: X11, GNOME, KDE), у сокета Sway или у сокета Hyprland.

Нужна группа `input` и доступ к `/dev/uinput`. После добавления в группу нужен новый вход в сессию. Если `/dev/uinput` доступен только root, хватает правила udev:

```
KERNEL=="uinput", GROUP="input", MODE="0660"
```

На самом Linux достаточно `cargo build --release`. Файл будет `target/release/zyabra`. С Windows та же сборка кроссом:

```
sudo usermod -aG input "$USER"
cargo build --release --target x86_64-unknown-linux-gnu
```

Кросс-сборка кладёт файл в `target/x86_64-unknown-linux-gnu/release/zyabra`. Окно закрывается крестиком, процесс после этого отпускает клавиатуру.

## Сборка

Нужен Rust.

```
cargo test
cargo build --release
```

Готовый файл Windows: `target/release/zyabra.exe`. В релизе он называется `zyabra-0.1.9.exe`: версия стоит после названия. Linux-файл в том же релизе называется `zyabra-0.1.9-linux-x86_64`. Подпись кода нет, SmartScreen может спросить подтверждение при первом запуске Windows-файла.

## Словари

Английский список — ENABLE, public domain. Русский — словоформы из [danakt/russian-words](https://github.com/danakt/russian-words), MIT. Подробности в `NOTICE.md`.

`tools/build_dicts.py` заново собирает `dictionaries/en.txt` и `dictionaries/ru.txt` из уже скачанных файлов в `third_party/`. Программа этот скрипт не запускает. В файл Зябры списки попадают сжатыми и разворачиваются в памяти при запуске.

Короткие добавки лежат отдельно: `dictionaries/extra-en.txt` и `dictionaries/extra-ru.txt`. Скрипт их не перезаписывает. Новое слово добавляется коммитом в репозиторий и попадает в программу при следующей сборке. Уже собранный файл строку сам не подхватывает.

В строке пишется слово того языка, которым оно является: строчными буквами, от 2 до 20 знаков. Пар словарь не хранит. Набранное меняется, только когда в своём списке его нет, а те же клавиши есть в другом. В английском списке есть `...`, поэтому `ююю` становится `...`: три "ю" по-русски словом не считаются, а эта клавиша по-английски печатает точку. В русский список добавляют слово, которого нет среди словоформ. Тогда набранное по-русски остаётся, а английские клавиши этого слова перекладываются в него, если сами словом не являются. Буква ё в строке пишется как е.

## Ограничения

- Только US QWERTY и стандартный ЙЦУКЕН. Фонетическая раскладка не поддерживается.
- Linux не видит, что фокус в поле пароля. На Wayland без XWayland, Sway или Hyprland раскладку спросить не у кого.
- Окна, запущенные от администратора, не видны: Зябра сама не просит права администратора.
- Поле пароля в браузере часто не помечено как пароль. Тогда текущее слово может оказаться в памяти, но на диск оно не пишется и в сеть не уходит.
- Слово, которого нет в словаре, программа сама не угадает. `Pause` перекладывает его по клавишам, и каждое следующее нажатие делает это снова.
- Перекладывание пропадает, если сдвинуть курсор или нажать Backspace по уже введённому тексту.
- Редкие совпадения возможны: бессмысленная строка иногда совпадает со словоформой. `Pause` перекладывает её обратно.

## English

Zyabra is a local RU/EN layout switcher. A word typed in the wrong layout is rewritten and the layout flips. Pause toggles that same word on every press. Another key can be added at launch with `--key CODE`; the window shows its name next to Pause, and Zyabra does not store the code. Short additions live in `dictionaries/extra-en.txt` and `dictionaries/extra-ru.txt` and are brought in by a commit; `...` is an English entry, so `ююю` is rewritten as `...`. The current word and that one replacement stay in memory. Nothing is written to disk, the clipboard is not used, and the program never opens a network connection.
